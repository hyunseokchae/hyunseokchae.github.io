업무 문제 & AI 적용 목표

Pain Points & AI Objectives
⚠ 업무 문제 (Pain Point)
문제설명
수익 누수무임·부정승차, 카드 미태그, 게이트 무단 통과로 운송수입 손실
단속 비효율단속 인력이 모든 역·시간대·게이트를 감시하기 어려움
오탐·민원 리스크잘못된 단속은 민원, 차별 논란, 운영 불신으로 이어질 수 있음
거래 이상 탐지 한계반복 환불, 비정상 할인, 카드 공유, 이상 환승 패턴 탐지 어려움
관제 분산CCTV·게이트 로그·AFC 거래·민원 데이터가 분리되어 종합 판단 어려움
🎯 AI 적용 목표
목표설명
부정승차 의심행동 탐지게이트 점프, tailgating, 역주행, 비정상 통과 탐지
이상거래 탐지반복 환불, 비정상 할인, 비정상 환승, 다중 카드 패턴
단속 우선순위 제공위험 점수 기반 단속 대상 역·시간대·게이트 추천
관제 알림 자동화이상행동·이상거래를 실시간/준실시간으로 관제센터에 알림
수익보호 강화누수 가능성 높은 패턴 조기 식별 → 정책 개선에 활용

탐지 대상 유형

Detection Target Types
📷 영상 기반 부정승차 유형
영상 탐지
Gate Jumping
게이트 위를 뛰어넘음
→ 객체검출 + 자세/행동 분석
영상 탐지
Crawling Under Gate
게이트 아래로 기어감
→ 자세추정 + 비정상 이동경로
영상 탐지
Pushing Gate
게이트를 밀고 강제 통과
→ 게이트 상태 로그 + 영상 행동
영상 탐지
Tailgating
앞사람 뒤를 붙어 무임 통과
→ 다중 인물 추적 + 단일 태그 비교
영상 탐지
Reverse Passage
반대 방향 비정상 통과
→ 이동 방향 추적 + 게이트 방향
영상 탐지
Open Gate Abuse
열린 게이트를 이용한 무단 통과
→ 게이트 개방 상태 + 태그 부재
💳 AFC 거래 기반 이상거래 유형
거래 탐지
비정상 환승
불가능한 시간·거리의 환승 패턴
→ Rule + Anomaly Detection
거래 탐지
반복 환불
특정 카드·계정의 환불 반복
→ 빈도 기반 이상탐지
거래 탐지
비정상 할인
할인 대상이 아닌 거래에 할인 적용
→ 룰 검증 + 이상탐지
거래 탐지
카드 공유 의심
동일 카드가 물리적으로 불가능한 위치에서 반복 사용
→ 시공간 이상탐지
거래 탐지
과도한 실패 태그
특정 카드·게이트에서 반복 실패
→ 로그 이상탐지
거래 탐지
비정상 정산
특정 역·운영사·시간대 정산 금액 급변
→ 통계적 이상탐지

FARE-009얼굴 인식 없이 행동과 거래 패턴 중심으로 탐지한다.
FARE-010의심 이벤트를 단속 근거가 아닌 "검토 대상"으로 표시한다.

요약

부정승차·이상거래 탐지는 CCTV 영상 기반 행동 탐지와 AFC 거래로그 기반 이상탐지를 결합하여, 게이트 무단 통과, tailgating, 반복 환불, 비정상 할인, 불가능 환승 등 수익 누수 가능성이 높은 이벤트를 조기에 식별하는 Anomaly Detection 유즈케이스이다. TfL의 Willesden Green Smart Station은 기존 CCTV와 AI 알고리즘을 활용하여 fare evasion 알림을 생성한 사례이며, 서울교통공사의 생성형 AI 기반 이상행동 탐지·추적 모델은 CCTV 영상을 상황 설명과 행동 패턴으로 변환하여 관제 대응을 고도화하는 방향을 제시한다. 본 유즈케이스는 단속 자동화가 아니라 AI 기반 위험 이벤트 선별, Human Review, 단속 우선순위 제공, 수익보호 정책 개선을 목표로 추진하는 것이 적절하다. 영상 AI와 AFC 거래 이상탐지를 결합해 수익 누수와 비정상 이용 패턴을 조기에 발견하고, 관제·단속·정산 업무의 효율성을 높이는 Revenue Protection 중심 AI 유즈케이스이다.
