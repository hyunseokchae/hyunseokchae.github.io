U11 · NLP/LLM

LLM 민원 챗봇 AI/ML 적용 프로세스

Passenger Complaint Chatbot — LLM/RAG 기반 자동응답 및 상담원 이관 체계

LLM 기반 민원 챗봇은 상담 로그·FAQ·약관·운영 매뉴얼을 지식 기반으로 구축하여 반복 문의를 자동응답하고, 금전·개인정보·법적 판단이 필요한 민원은 상담원에게 안전하게 이관한다. Intent 분류 → RAG 검색 → LLM 답변 생성 → Guardrail 검증의 파이프라인으로 1차 응대 자동화율 60%+ 달성을 목표로 하며, 모니터링·재학습 체계를 통해 지속적으로 품질을 개선한다.
