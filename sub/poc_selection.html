시간대·역별 수요 예측 PoC

Demand Forecasting PoC

AFC 승하차 로그를 기반으로 시간대·노선·역별 수요를 예측하여 배차 최적화와 운영비 절감을 실현하는 시계열 예측 과제이다.

처리 흐름
AFC 승하차 로그 수집
▼
EDA 및 시계열 패턴 분석
▼
Feature Engineering (날씨·이벤트·계절성)
▼
ML 모델 학습 (XGBoost / Prophet / LSTM)
▼
수요 예측값 산출 (D+1~D+7)
▼
배차·인력 계획 연계 대시보드
대표 예측 대상
  • 러시아워 시간대 노선별 혼잡도 예측
  • D+1~D+7 30분 단위 역별 수요 예측
  • 이벤트·공휴일 비정상 수요 사전 인식
  • 역별·노선별 계절성 수요 변동 예측
  • 배차 인력 계획 수립을 위한 수요 시나리오 제공
장점
장점설명
레이블 불필요AFC 거래 로그만으로 시작 가능 — 부정승차 탐지 대비 데이터 준비 부담 낮음
내부 검증 용이예측값과 실제값 비교(MAPE)만으로 모델 성능 평가 가능
정량 ROI 명확운영비 절감 −3~7%, MAPE 목표 수치화 가능
업무 임팩트 큼배차·인력 계획 최적화로 직접 운영비 절감
데이터 구조 명확시계열 형태로 모델링 패턴이 잘 확립되어 있음
확장 가능성 높음다변수 모델, 실시간 예측, 시뮬레이션 도구로 고도화 가능
단점
단점설명
3개월 정확도 불확실PoC 기간 내 목표 MAPE 달성 여부가 데이터 품질에 따라 달라짐
외부 데이터 연동 필요날씨·이벤트 데이터 연계가 없으면 예측 정확도 제한
운영 배차 연동 없으면 한계배차 시스템과 연결되지 않으면 실효성 검증이 어려움
시연 가시성 낮음챗봇 대비 비전문가에게 결과물 설명이 어려울 수 있음
이력 데이터 기간 필요계절성 반영을 위해 최소 1년 이상 AFC 데이터 권장

Bottom Line

내부 테스트형 3개월 PoC라면 LLM 민원 챗봇이 가장 현실적인 1순위 선택이다.

수요 예측은 AFC 거래 로그만으로 착수 가능하며, 운영비 절감 ROI가 명확해 이력 데이터 확보 즉시 2순위 대안으로 추진 권장한다.
부정승차 탐지는 라벨·운영 데이터 체계가 갖춰진 후 중장기 과제로 추진하는 것이 안전하다.
