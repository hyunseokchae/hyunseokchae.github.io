Deutsche Bahn · Germany

대규모 영상 인프라 + 보안 이벤트 플랫폼

DB는 약 1,000개 역에 약 11,000대의 현대식 영상 카메라를 운영하며, 배차·교통통제·모니터링에 활용한다. DB Systel의 Corporate Security Platform은 안전·보안 이벤트를 실시간 기록·평가하고 즉시 대응하는 방향을 명시한다. AI 탐지는 관제·출동·응급대응과 결합되어야 효과를 극대화한다.

Network Rail · UK

Edge AI + 이벤트 라우팅 + 직원 알림

Network Rail은 TSIP/ASAP 프로그램을 통해 스마트 카메라·센서 기반 분석을 추진한다. SiYtE 플랫폼이 이벤트를 집계하여 담당 직원·현장 순찰까지 알림을 라우팅한다. 8개 역 AI 실증에서 선로침입, 플랫폼 혼잡, 반사회적 행동, 자전거 관련 사건이 탐지 대상이었다.

해석 주의: DB는 "영상 인프라·보안 플랫폼" 근거가 강하고, Network Rail은 "AI CCTV 분석 실증" 근거가 직접적이다. DB 사례는 적용 기반·확장 가능성 중심으로, Network Rail 사례는 실증 유즈케이스 중심으로 해석한다.

업무 문제 및 AI 적용 목표

3.1 업무 문제

문제설명
수동 모니터링 한계대형 역사는 CCTV 수가 많아 관제 인력이 모든 영상을 실시간으로 집중 모니터링하기 어려움
사고 발견 지연낙상·선로침입 등 초 단위 대응이 필요한 이벤트도 수동 모니터링 체계에서는 발견이 지연됨
대응 시간 초과발견 지연으로 관제·현장 대응이 늦어지고 피해가 확대됨
경험 의존적 모니터링이상 징후 판단이 운영자 개인의 경험과 집중도에 의존함
사후 분석 비효율사건 발생 후 영상 검색·확인에 많은 시간이 소요됨
위험구역 식별 부족어떤 역, 어떤 구역에서 반복적으로 위험 상황이 발생하는지 데이터가 없음

3.2 AI 적용 목표

목표설명
낙상·선로침입 실시간 탐지낙상·선로침입 이벤트를 발생 즉시 자동 탐지하고 관제 알림 발송
이상행동 식별달리기·싸움·배회·금지행위 등 위험행동 자동 분류
군중 이상 탐지플랫폼·게이트·환승통로의 혼잡 급증 및 정체를 실시간 감지
관제 대응시간 단축이벤트 발생부터 관제 확인, 현장 출동까지 시간 대폭 단축
사후 분석 자동화이벤트 클립, 스냅샷, 메타데이터 자동 생성으로 사건 조사 효율화
위험구역 데이터 축적이벤트 유형·위치·시간 데이터를 축적하여 위험구역 패턴 분석
개인식별 배제얼굴인식·감정분석 없이 안전 이벤트 탐지 목적에만 집중
4

탐지 대상 구역 및 시나리오

4.1 적용 구역 (5개 구역)

Critical Zone
플랫폼

위험: 선로 추락, 엣지 접근, 군중 밀집
탐지: 낙상, 선로침입, 위험구역 체류, 혼잡 급증

Safety Zone
역사 통로/대합실

위험: 쓰러짐, 배회, 폭력행동, 방치물
탐지: Person Down, 장시간 정지, 이상행동, 방치물

Control Zone
게이트/개집표 구역

위험: 무단진입, 역주행, 충돌, 혼잡
탐지: 비정상 이동방향, 군중 정체, 쓰러짐

Risk Zone
에스컬레이터/계단

위험: 넘어짐, 역주행, 정체, 끼임
탐지: 낙상, 비정상 정지, 역방향 이동, 밀집

Restricted Zone
차량기지/야간 무인구역

위험: 침입, 기물파손, 위험물 접근
탐지: 비인가 침입, 장시간 체류, 이상 움직임

4.2 낙상 / Person Down 탐지 시나리오

항목상세 내용
탐지 대상플랫폼, 통로, 대합실, 계단, 에스컬레이터 인근에서 사람이 쓰러지거나 일정 시간 누워 있는 상태
탐지 로직사람 객체 탐지 → 관절/바운딩박스 비율 분석 → 급격한 자세 변화 확인 → 미이동 지속시간 확인 → 이벤트 발생
주요 Feature바운딩박스 가로/세로 비율, 머리-발 위치, 관절 각도, 중심점 속도, 바닥 근접도, 미이동 시간
오탐 요인벤치에 눕기, 짐을 줍는 동작, 아이가 앉거나 기어가는 동작, 청소·정비 작업자 자세
오탐 저감3~5초 Temporal Window, 사람 자세 추적, 작업구역 예외처리, 관제 확인 단계 적용
대응관제 화면 자동 팝업, 위치 표시, 현장요원 출동, 필요 시 응급대응 프로토콜 전환

4.3 선로침입 / 플랫폼 엣지 위험 탐지 시나리오

항목상세 내용
탐지 대상선로 영역 진입, 플랫폼 경계선 초과, 플랫폼 엣지 장시간 체류, 위험구역 반복 접근
탐지 로직카메라별 ROI 설정 → 사람 객체 추적 → ROI 침범 여부 판단 → 열차 접근·운영상태 결합 → 위험등급 산정
우선순위열차 접근 중 선로침입: Critical   열차 미접근 선로침입: High   엣지 반복 접근: Medium
예외처리작업자 PPE, 승인 작업시간, 작업 허가구역, 정비 모드, 열차 미운행 시간대
대응관제 알림, 역무원 출동, 안내방송, 열차운영 통제 연계, 사고 로그 자동 생성

4.4 이상행동 / 반사회적 행동 탐지 시나리오

행동 유형AI 판단 기준운영 대응
달리기·급격한 이동평균 보행속도 대비 급격한 이동, 충돌 위험, 게이트 역주행혼잡구역 경고, 현장 직원 확인
폭력·싸움 의심다수 인물의 급격한 접근·후퇴·팔 동작·넘어짐 패턴보안요원 출동, 관련 카메라 자동 고정
장시간 배회동일 구역 반복 이동, 목적지 없는 왕복, 야간 무인구역 체류관제 확인 후 순찰 지시
흡연·스케이트보드 등 금지행위특정 객체/자세/이동패턴 탐지, 규칙 기반 위험구역 판정현장 안내, 경고방송, 보안 기록

4.5 군중 이상 / 혼잡 급증 탐지 시나리오

항목상세 내용
탐지 대상플랫폼, 게이트, 환승통로, 계단, 에스컬레이터 앞 군중 밀집 및 이동정체
탐지 지표구역별 인원수, 밀도, 평균 이동속도, 역방향 흐름, 병목 지속시간, 인원 유입·유출 비율
위험 판단밀도 임계값 초과, 이동속도 급감, 특정 방향 흐름 집중, 플랫폼 엣지 근접 인원 증가
대응동선 유도, 게이트 개방 조정, 안내방송, 현장 인력 배치, 열차 도착 정보 연계

6.4 탐지 판단식 예시

낙상 탐지 (Fall_Score)

Fall_Score = 0.30 × Sudden_Posture_Change + 0.25 × BBox_Aspect_Ratio_Change + 0.20 × Low_Body_Position + 0.15 × No_Movement_Duration + 0.10 × ROI_Risk_Level IF Fall_Score ≥ Threshold AND No_Movement ≥ 3s THEN → "Person Down" Event

선로침입 탐지 (Rule-based)

IF object.class == "person" AND object.center IN Track_ROI AND NOT worker_authorized( object, time, zone) THEN event.type = "Track Intrusion" event.severity = "Critical" notify( control_center, station_staff, train_operation_center )

8.2 통합 분석 유스케이스

낙상 이벤트 발생 구역의 시간대, 유입량, 바닥센서, 설비장애, 혼잡도 데이터를 결합해 특정 구역의 반복 사고 원인을 분석한다.

요약

CCTV 영상 이상행동·낙상 탐지 유즈케이스는 역사·플랫폼·통로의 CCTV 영상을 Edge AI로 실시간 분석하여 낙상·선로침입·이상행동·군중 이상 등 안전 이벤트를 자동 탐지하고, 관제센터와 현장 인력에게 즉시 알림을 제공하는 스마트 역사 안전 관제 체계이다.

Deutsche Bahn의 약 11,000대 현대식 카메라 인프라와 Corporate Security Platform은 AI 이벤트를 통합 보안 플랫폼으로 연계하는 설계 방향을 제시하며, Network Rail의 TSIP/ASAP 실증은 선로침입·혼잡·반사회적 행동 탐지를 위한 Edge AI + 이벤트 라우팅 + 직원 알림 체계의 직접적인 벤치마크를 제공한다.

본 유즈케이스는 승강장 안전 확보, 관제 대응 자동화, 사후 분석 효율화, AFC 연계 통합 안전 관제의 핵심 기반이 된다.
