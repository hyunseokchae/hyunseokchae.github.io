Microsoft Azure — Medallion Architecture + MLOps 7계층 상세 설계

AFC(자동요금징수) 도메인 AI/ML 플랫폼의 전체 Azure 서비스 구성을 계층별로 정의합니다. Bronze→Silver→Gold 메달리온 데이터 레이크 위에 Azure Machine Learning 기반 ML 파이프라인을 구축하고, Azure DevOps + MLOps 자동화를 통해 18개 유즈케이스를 단계적으로 운영합니다.
전체 구조 데이터 흐름 7계층 상세 MLOps 보안·거버넌스 서비스 선택 AWS vs Azure

계층별 Azure 서비스 상세

Layer-by-Layer Azure Service Detail
계층 주요 Azure 서비스 선택 이유 AFC 적용 포인트
1. Data Ingestion ADF, Event Hubs, Stream Analytics, IoT Hub, APIM ADF CDC 커넥터로 운영 DB 부하 없이 실시간 변경 복제 / Event Hubs Kafka 호환 게이트 IN/OUT 이벤트 즉시 스트리밍 → 부정승차 실시간 탐지 피처 생성
2. Data Lake ADLS Gen2, Microsoft Purview, Databricks, Synapse Analytics Purview 데이터 맵으로 민감 컬럼 자동 분류·접근 제어 / Delta Lake ACID 보장 Bronze 적재 즉시 카드 ID → SHA-256 가명화 / Synapse에 OD 분석 마트 구축
3. Feature Layer Azure ML Feature Store, Synapse, Databricks, Azure Functions MLflow 통합 피처 메타데이터 / Databricks Feature Store 공유로 팀 간 재사용 역별·시간대별 피처 공유 (수요예측 + 혼잡도 예측 동시 활용)
4. ML Platform Azure ML Training, Experiments(MLflow), Model Registry, AutoML, ACR Spot VM 활용으로 학습 비용 최대 80% 절감 / MLflow 오픈소스 통합 XGBoost(부정승차), LSTM(수요예측), Isolation Forest(이상거래) 컨테이너 분리 관리
5. Serving Batch Endpoints, Online Endpoints, Async Inference, Redis, APIM Blue-Green Deployment 기본 지원 / Traffic Split으로 A/B 테스트 내장 Phase 1: 일배치 단속 리스트 → Phase 2: 5분 주기 혼잡도 → Phase 3: 실시간 낙상 탐지
6. Monitoring Azure ML Model Monitor, Azure Monitor, Managed Grafana, Defender, Alerts Application Insights 통합으로 엔드포인트 지연·오류 추적 일원화 설날·추석·콘서트 등 비정기 이벤트로 인한 수요 패턴 급변 자동 감지
7. Business App Power BI, Service Bus, Logic Apps, APIM, Static Web Apps Power BI Embedded로 업무 시스템 내 대시보드 직접 삽입 / M365 연동 용이 단속 담당자 Service Bus 큐 → Teams/모바일 알림 / Logic Apps → 티켓 자동 생성

AWS vs Azure 서비스 대조표

AWS ↔ Azure Equivalent Services
계층 ☁️ AWS ☁️ Azure 비고
CDC / 스트리밍 수집 AWS DMS · Kinesis Data Streams · Kinesis Firehose Azure Data Factory (ADF) · Event Hubs · Stream Analytics Event Hubs는 Kafka 호환 프로토콜 지원
IoT 수집 AWS IoT Core · Greengrass Azure IoT Hub · IoT Edge AFC 게이트 IoT 센서 엣지 처리
데이터 레이크 스토리지 Amazon S3 (Bronze/Silver/Gold) ADLS Gen2 (Bronze/Silver/Gold) Azure는 계층형 네임스페이스로 폴더 ACLS 지원
데이터 거버넌스 AWS Lake Formation · Macie Microsoft Purview Purview는 Macie+Lake Formation 역할 통합
데이터 카탈로그 AWS Glue Data Catalog Microsoft Purview Data Map Azure는 비즈니스 용어집·계보 추적 내장
대화형 쿼리 Amazon Athena Azure Synapse Serverless SQL 모두 S3/ADLS 위 서버리스 쿼리
데이터 웨어하우스 Amazon Redshift Azure Synapse Analytics (Dedicated Pool) Synapse는 레이크+웨어하우스 통합 플랫폼
Spark ETL AWS Glue ETL · EMR Azure Databricks · Synapse Spark Databricks는 양 클라우드 모두 제공 (멀티클라우드)
Feature Store SageMaker Feature Store Azure ML Feature Store 둘 다 Offline+Online 이원화 지원
ML 학습 플랫폼 Amazon SageMaker Training Azure Machine Learning Azure ML은 MLflow 네이티브 통합
AutoML SageMaker Autopilot Azure AutoML Azure AutoML은 시계열 전용 모드 제공
컨테이너 레지스트리 Amazon ECR Azure Container Registry (ACR) —
모델 서빙 (배치) SageMaker Batch Transform Azure ML Batch Endpoints —
모델 서빙 (실시간) SageMaker Real-time Endpoints Azure ML Managed Online Endpoints Azure는 Blue-Green 기본 내장
추론 캐싱 Amazon ElastiCache (Redis) Azure Cache for Redis —
모델 모니터링 SageMaker Model Monitor Azure ML Model Monitor 둘 다 Data/Model/Bias Drift 지원
인프라 모니터링 Amazon CloudWatch Azure Monitor + Application Insights Application Insights는 APM 기능 포함
시각화 대시보드 Amazon Managed Grafana Azure Managed Grafana · Power BI Power BI는 비개발 업무 부서 활용에 유리
알림 Amazon SNS · SQS Azure Service Bus · Event Grid Service Bus는 엔터프라이즈 메시징 특화
워크플로 오케스트레이션 AWS Step Functions Azure Logic Apps · Durable Functions Logic Apps는 Low-code 커넥터 300+ 기본 제공
ML CI/CD AWS CodePipeline · CodeBuild Azure DevOps Pipelines · GitHub Actions Azure DevOps는 Board·Repo·Pipeline 통합
IaC AWS CDK · CloudFormation Bicep · Terraform Terraform은 멀티클라우드 표준으로 권장
LLM / Gen AI Amazon Bedrock Azure OpenAI Service Azure는 GPT-4o, o1, DALL-E 등 직접 연동
Responsible AI SageMaker Clarify Azure ML Responsible AI Dashboard Azure RAI는 해석 가능성·공정성 분석 통합
