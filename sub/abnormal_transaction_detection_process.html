업무 문제 정의

Problem Definition
1.1 목적

AFC 또는 결제 시스템에서 발생하는 거래 중 정상 패턴과 다른 거래, 부정 사용 가능성이 높은 거래, 시스템 오류 또는 정산 오류 가능성이 있는 거래를 조기에 식별한다.

// 업무 문제 정의 예시
AFC 거래 데이터에서 정상 이용 패턴과 다른 비정상 거래를 탐지하여
부정승차, 카드 오남용, 장비 오류, 정산 오류, 비정상 환불·취소 거래를 조기에 식별한다.
1.2 탐지 대상 유형
구분이상거래 유형설명
카드 사용 이상동일 카드 반복 태그짧은 시간 내 동일 카드가 비정상적으로 반복 사용
공간 이동 이상불가능한 이동 패턴물리적으로 불가능한 시간 내 먼 거리 이동
요금 이상비정상 요금무료/할인/고액/음수 요금 등 업무 규칙 위반 가능
장비 이상특정 장비 오류 집중특정 단말기 또는 게이트에서 이상 거래 급증
시간 이상운영시간 외 거래영업시간 외 또는 비정상 시간대 거래 발생
환불/취소 이상반복 환불·취소특정 카드/계정/채널에서 환불·취소 과다 발생
계정 이상다중 기기 사용하나의 계정이 여러 기기·지역에서 비정상 사용
정산 이상집계 불일치거래 금액과 정산 금액 간 차이 발생
1.3 업무 사용자 정의
사용자활용 목적
운영센터실시간 이상 징후 확인 및 현장 대응
정산 담당자수익 누락, 정산 오류, 비정상 환불 확인
부정승차 단속팀부정 사용 의심 대상 선별
장비 유지보수팀장비 오류 기반 이상거래 확인
데이터 분석팀이상 패턴 분석 및 모델 개선
고객센터민원 발생 시 거래 이상 여부 확인
목표예시 KPI
부정거래 조기 탐지의심거래 탐지율 80% 이상
오탐 최소화False Positive Rate 10% 이하
운영 효율화수작업 검토 대상 50% 절감
정산 안정성 향상정산 오류 후보 자동 식별
장비 장애 조기 감지장비 이상거래 급증 사전 탐지

Conclusion & Key Principles

이상거래 탐지 AI/ML 적용은 모델 개발보다 정확한 업무 문제 정의와 데이터 품질 분석이 우선이다. 특히 AFC/결제 환경에서는 이상거래의 정답 라벨이 부족하거나 희소한 경우가 많기 때문에, 초기에는 아래의 단계적 접근이 현실적이다.

1

R-001~R-007 룰로 즉시 탐지 시작
↓

3

↓
4

↓
5
단계적 지도학습 고도화
Label 축적 후 XGBoost/LightGBM 적용
이 접근 방식은 초기 검증 성공 가능성을 높이고, 운영 현장의 검토 부담을 줄이며, 장기적으로 재학습 가능한 이상거래 탐지 체계를 구축하는 데 적합하다.
