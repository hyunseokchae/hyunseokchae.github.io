GCP · Google Cloud Platform · Vertex AI

AFC AI/ML 시스템 아키텍처 — GCP 기반

Google Cloud Platform Medallion Architecture + Vertex AI MLOps

Google Cloud Platform(GCP)의 Vertex AI · BigQuery · Cloud Storage를 기반으로 AFC 도메인 AI/ML 파이프라인을 구성한다. BigQuery의 페타바이트급 분석 성능과 Vertex AI의 완전 관리형 MLOps 플랫폼을 결합하여 데이터 수집 → 특성 엔지니어링 → 모델 학습·배포 → 모니터링까지 통합 자동화 아키텍처를 제공한다.

AFC 규모별 GCP 서비스 가이드

GCP Sizing Guide by AFC Scale
AFC 규모일 거래 건수권장 GCP 구성BigQuery 예상 비용
소규모~100만 건Cloud Composer(소) · BigQuery On-Demand · Vertex AI Shared월 $200~500
중규모100~500만 건Cloud Composer(중) · BigQuery Capacity Slots · Vertex AI Dedicated월 $1,000~3,000
대규모500만 건+Cloud Composer HA · BigQuery Enterprise · Vertex AI Enterprise월 $5,000+
GCP 비용 최적화 팁: BigQuery Reservations(슬롯 예약) 활용 시 On-Demand 대비 최대 50% 절감 가능. Vertex AI Training은 Spot VM(선점형 VM) 사용 시 최대 70% 절감. Cloud Storage 수명 주기 정책으로 Bronze 데이터 Nearline/Coldline 자동 전환.
GCP 선택 권장 시나리오: ① BigQuery ML로 빠른 PoC가 필요한 경우 ② Google Maps/교통 데이터와 연계가 필요한 경우 ③ Looker로 고급 BI 분석 환경을 구성할 경우 ④ 기존 Google Workspace 환경과 통합이 필요한 경우
