AWS Cloud — Medallion Architecture + MLOps 7계층 상세 설계

AFC(자동요금징수) 도메인 AI/ML 플랫폼의 전체 AWS 서비스 구성을 계층별로 정의합니다. Bronze→Silver→Gold 메달리온 데이터 레이크 위에 SageMaker 기반 ML 파이프라인을 구축하고, MLOps 자동화를 통해 18개 유즈케이스를 단계적으로 운영합니다.

계층별 AWS 서비스 상세

Layer-by-Layer AWS Service Detail
계층 주요 AWS 서비스 선택 이유 AFC 적용 포인트
1. Data Ingestion DMS, Kinesis, Glue, API Gateway, Transfer Family CDC(변경 데이터 캡처)로 운영계 부하 없이 실시간 복제 게이트 IN/OUT 이벤트 즉시 스트리밍 → 부정승차 실시간 탐지 피처 생성
2. Data Lake S3, Lake Formation, Glue Catalog, Athena, Redshift Lake Formation 컬럼 수준 FGAC로 교통카드 ID 익명화 레이어 강제 적용 Bronze 적재 즉시 카드 ID → SHA-256 가명화 / Redshift에 OD 분석 마트 구축
3. Feature Layer SageMaker Feature Store, Redshift, Glue ETL, Lambda Offline(학습 일관성) + Online(저지연 추론) 이원화 / 피처 재사용으로 개발 속도 향상 역별·시간대별 피처 공유 (수요예측 + 혼잡도 예측 동시 활용)
4. ML Platform SageMaker Training, Experiments, Model Registry, Autopilot, ECR Managed Spot Training으로 학습 비용 최대 90% 절감 XGBoost(부정승차), LSTM(수요예측), Isolation Forest(이상거래) 컨테이너 분리 관리
5. Serving Batch Transform, Async Inference, Real-time Endpoints, ElastiCache, API Gateway Phase별 비용-성능 최적화 / ElastiCache로 반복 추론 캐싱 Phase 1: 일배치 단속 리스트 → Phase 2: 5분 주기 혼잡도 → Phase 3: 실시간 낙상 탐지
6. Monitoring SageMaker Model Monitor, CloudWatch, Managed Grafana, CloudTrail, SNS 자동 재학습 트리거로 계절성·이벤트 드리프트 대응 설날·추석·콘서트 등 비정기 이벤트로 인한 수요 패턴 급변 자동 감지
7. Business App QuickSight, SNS/SQS, Step Functions, AppSync, Amplify QuickSight ML Insights로 anomaly 자동 하이라이트 단속 담당자 SQS 큐 → 모바일 앱 푸시 / 정비 Step Functions → 티켓 자동 생성
