승객 민원 챗봇·음성 응대

Passenger Complaint Chatbot & Voice Response

AFC 승객의 요금 문의·카드 오류·환승 불편·분실물·안전 신고 등 다양한 민원을 AI 챗봇과 음성 에이전트가 24/7 자동 응대함으로써 콜센터 비용 절감, 평균 처리시간 단축, 고객 만족도 향상을 동시에 달성한다. RAG(Retrieval-Augmented Generation) 기반 지식 검색과 LLM 생성을 결합하여 환각(Hallucination) 위험을 최소화하고, 복잡한 민원은 자동으로 상담원에게 이관한다.

LLM 가드레일 설계

LLM Guardrail Design
입력 가드레일 (Input Guardrail)
function inputGuardrail(userMessage) { // 1. PII 감지 및 마스킹 if (detectPII(userMessage)) { userMessage = maskPII(userMessage); // 카드번호, 주민번호 등 } // 2. 긴급·안전 트리거 즉시 이관 if (detectEmergencyTrigger(userMessage)) { return escalateToHuman("EMERGENCY"); } // 3. 주제 범위 외 질문 차단 if (isOutOfScope(userMessage)) { return rejectWithGuide("교통·AFC 관련 문의만 처리 가능합니다."); } return userMessage; }
출력 가드레일 (Output Guardrail)
function outputGuardrail(llmResponse, retrievedDocs) { // 1. 자신감 점수 기반 응답 제어 if (llmResponse.confidence < 0.7) { return escalateToHuman("LOW_CONFIDENCE"); } // 2. 환각 탐지: 출처 없는 사실 주장 차단 if (!isGroundedInDocs(llmResponse, retrievedDocs)) { return fallbackToFAQ(); // RAG 문서 기반 응답으로 대체 } // 3. 금지 토픽 후처리 (법적 조언, 환불 보장 등) filterProhibitedTopics(llmResponse); // 4. 출처 및 면책 조항 자동 첨부 return appendDisclaimer(llmResponse, retrievedDocs.sources); }
가드레일 체계 요약
분류항목처리 방식
PII 보호카드번호·주민번호·연락처입력 단계 마스킹, 로그 저장 금지
긴급 이관안전·의료·법적 분쟁즉시 상담원 전환 + 알림
환각 차단근거 없는 사실 주장RAG 출처 검증 후 미일치 시 거부
자신감 임계신뢰도 < 0.7불확실 시 이관 또는 재문의 유도
주제 범위AFC 외 무관 질문정중한 거절 + 안내 메시지

전처리 파이프라인
  1. 문서 파싱: PDF/HTML → 청크 분리 (512 토큰 단위, 20% 오버랩)
  2. 임베딩 생성: text-embedding-3-large 또는 multilingual-e5-large
  3. 벡터 인덱싱: HNSW 알고리즘으로 근사 최근접 이웃 구성
  4. 메타데이터 태깅: 문서 유형·날짜·우선순위 부여
  5. 갱신 자동화: 데이터 변경 이벤트 감지 → 증분 인덱싱
  6. 품질 검증: 검색 정밀도(Precision@5) 주기적 평가
⚠️ 개인정보 처리 원칙
  • 대화 이력은 세션 종료 후 90일 보관 후 자동 파기 (개인정보보호법 준수)
  • 카드번호·주민번호 등 민감 정보는 입력 즉시 마스킹, 벡터 DB에 저장 불가
  • 민원 학습 데이터는 개인식별정보 제거 후 익명화 처리
  • 음성 데이터는 STT 변환 완료 후 즉시 삭제 (녹음 보관 별도 동의 필요)
  • EU GDPR / 국내 개인정보보호법 이중 준수 체계
