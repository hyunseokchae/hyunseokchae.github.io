U01 · Forecasting / Time-Series

시간대·역별 수요 예측 AI/ML 적용 프로세스

Passenger Demand Forecasting — AFC 거래 데이터 기반 시계열 예측 및 운영 최적화

AFC 거래 데이터를 기반으로 시간대·역·노선별 승차 수요를 예측하여 배차 계획·인력 배치·혼잡 대응 등 운영 의사결정을 자동화한다. 과거 거래 패턴, 요일·공휴일·이벤트 등 외부 요인을 결합한 Prophet · LSTM · XGBoost 앙상블 모델로 MAPE 10% 이하의 예측 정확도를 목표로 하며, 예측 결과는 운영 스케줄 시스템에 자동 연계된다.

업무 문제 정의

Business Problem Definition
현재 문제점
  • 수동 배차 계획: 담당자 경험에 의존하여 피크·비피크 대응이 지연됨
  • 과잉·과소 운영: 수요 예측 부재로 혼잡 또는 공차 운행 빈발
  • 이벤트 대응 미흡: 스포츠 경기·공휴일·파업 등 특수 상황 대응이 임시방편에 그침
  • 운영비 낭비: 비효율적 배차로 인한 인건비·연료비 증가
  • 데이터 미활용: AFC 시스템에 수년간 누적된 거래 데이터가 분석에 활용되지 않음
AI 적용 목표
  • 30분 단위 수요 예측: 역·노선·방향별 승차량 사전 예측
  • 배차 최적화: 예측 결과를 운영 시스템에 자동 피드백
  • 이벤트 보정: 공휴일·행사·날씨 변수 자동 반영
  • 운영비 절감: MAPE 10% 이하 달성 시 운영비 3~7% 절감 기대
  • 혼잡 사전 경보: 예측 초과 구간 사전 알림으로 혼잡 대응 시간 단축
예측 대상 범위
구분상세비고
예측 단위역별 × 30분 슬롯 × 방향(승·하차)최소 단위 기준
예측 horizon당일 ~ D+7 (1주일 선행)배차 계획 주기 고려
예측 갱신 주기매일 오전 배치 실행 (익일~D+7 갱신)실시간 보정 옵션 추가 가능
집계 수준역별·노선별·전체 시스템별 3단계대시보드 레벨별 제공

탐색적 데이터 분석 (EDA)

Exploratory Data Analysis
시간 패턴 분석
  • 시간대별 피크: 평일 07~09시, 17~20시 이중 피크 구조 확인
  • 요일 효과: 월~금 평일 대비 토요일 70%, 일요일 55% 수준
  • 계절성: 연간 주기(휴가철 감소), 월간 주기(월말 증가) 패턴
  • 공휴일 효과: 공휴일 전날 저녁 피크 증가, 당일 주간 감소
역별·노선별 패턴 분석
  • 환승역 집중: 환승역 5곳에서 전체 승차량 40%+ 집중
  • 방향성 비대칭: 아침 도심 방향 피크, 저녁 외곽 방향 피크
  • 역 클러스터: 업무지구·주거지·대학가·쇼핑지구 4개 유형 식별
  • 이벤트 영향: 경기장·공연장 인근 역에서 이벤트일 3~5배 급증
이상 패턴 식별
시스템 장애 이상치
게이트 장애·시스템 다운 시 특정 역 거래량 급감 → 운영 장애 이력과 교차 검증 필요
계절·이벤트 급증
카니발·스포츠 결승전 등 특수 이벤트 시 정상 패턴 3~10배 이탈 → 별도 이벤트 모델링 필요
요금 정책 변경 영향
요금 인상·할인 정책 변경 직후 일시적 수요 변동 → 정책 변경일 기준 구조 변화점(Changepoint) 처리
